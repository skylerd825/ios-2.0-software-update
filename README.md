# iOS 2.0 Software Update Web App

A prototype mimicking the vintage iOS 2.0 Software Update UI interface. Designed to test direct static application deployments seamlessly.

## 🚀 Instant Deployment Guide

### GitHub Pages Setup
1. Upload these repository files to your own GitHub profile.
2. Navigate to **Settings** -> **Pages**.
3. Under *Build and deployment*, set the Source branch to `main` (or root context) and click **Save**.

### GitHub Codespaces Setup
1. Click the **Code** dropdown button on your repository page.
2. Select the **Codespaces** layout tab, then click **Create codespace on main**.
3. Once running, VS Code will forward port `5500` or handle hot-reloads automatically via your browser.
